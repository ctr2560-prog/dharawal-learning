VOCAB IMAGE FOLDER
==================
Drop image files here to use them in the Word Matching game.

NAMING — use the English word, lowercase, spaces → hyphens:
  kangaroo.png
  koala.jpg
  fresh-water-turtle.png
  sea-turtle.jpg
  ear.png
  beach.jpg

Supported formats: .png  .jpg  .jpeg  .webp

If no image is found for a word, the game shows an emoji instead.
The image area is 160×160px — square images work best.
